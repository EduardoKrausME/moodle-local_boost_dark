**Boost Dark Mode** started more as a proof than as a feature: a way to show that a proper dark mode in Moodle was possible. The project began by proving that the interface could support a usable dark experience without waiting for native support in Moodle itself. Once something is proven possible and works in real installations, the path becomes much easier for everyone else to follow.

With Moodle 5.3, Boost now includes native colour modes, including light, dark and automatic modes. When the native Boost setting `theme_boost | defaultcolourmode` is set to `dark` or `auto`, this plugin automatically steps aside and leaves Moodle's native implementation in control.

A huge thank you to everyone who installed the plugin, tested it, reported problems, suggested improvements, shared feedback or helped in any other way. What started as a proof of concept became useful on real Moodle sites because people actually used it and helped improve it.

This does not mean the plugin is going away. At the launch of Moodle 5.3 in October 2026, roughly 80% of the registered Moodle sites were still running Moodle 5.1 or earlier, according to [Moodle statistics](https://stats.moodle.org/). If Moodle 5.2 is also included, the overwhelming majority of installations are still below Moodle 5.3. Those sites do not yet have Boost's native dark mode and will continue to need a solution like this, so **Boost Dark Mode will remain available and active for a long time yet**.

## 🚀 Features

- Activates a dark mode button in the Boost theme header.
- Saves the user's dark mode preference using their preferences, ensuring settings remain consistent across browsers.
- Simple and lightweight, with no interference in any standard Boost functionality.

## 📚 How to Use

1. Access your Moodle with the Boost theme activated.
2. In the upper corner, click the **Dark Mode** icon to toggle between light and dark modes.
3. The setting will be saved in the user's preferences and automatically applied whenever they return to Moodle.

## 📦 Installation

Visit the plugin page at [https://moodle.org/plugins/local_boost_dark](https://moodle.org/plugins/local_boost_dark) and install the plugin as usual.
